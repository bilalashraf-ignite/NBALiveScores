Install @next/bundle-analyzer and configure bundle optimization:

1. Install bundle analyzer:
   ```bash
   npm install --save-dev @next/bundle-analyzer
   ```

2. Update next.config.ts to enable bundle analyzer with environment variable control:
   - Import withBundleAnalyzer from '@next/bundle-analyzer'
   - Wrap existing config with withBundleAnalyzer({ enabled: process.env.ANALYZE === 'true' })
   - Preserve all existing config (runtime, cache headers, etc.)

3. Convert GameDetailModal to lazy-loaded dynamic import in src/app/page.tsx:
   - Import dynamic from 'next/dynamic'
   - Replace direct import with: `const GameDetailModal = dynamic(() => import('@/components/game-detail-modal'), { loading: () => <GameDetailSkeleton />, ssr: false })`
   - Modal loads on first click, not at initial page load
   - ssr: false because modal uses browser-only APIs (Radix Dialog)
   - Loading fallback shows skeleton during first load

This separates modal + stats components (TeamStatsTable, PlayerStatsTable, HistoricalMatchup) into separate bundle chunk loaded on demand.

Why ssr: false: Modal uses browser-only APIs like window.history (useModalHistory hook). Dynamic imports still run during SSR without this flag, causing build errors.

    * - No FOUT/FOIT (Flash of Unstyled/Invisible Text)

    * - Native feel familiar to users
    */

Why system fonts: Zero network cost, instant rendering, no web font download delay, respects user's OS settings
Why -apple-system first: Targets San Francisco font on macOS/iOS, most polished system font
Why include emoji fonts: Ensures emoji render correctly across platforms
