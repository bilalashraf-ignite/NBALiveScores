  <files>next.config.js, public/.gitkeep</files>
  <action>
Configure Next.js for optimal CDN delivery (addresses PERF-04):
- Update next.config.js to set cache headers:
  ```javascript
  module.exports = {
    images: {
      formats: ['image/avif', 'image/webp'],
      deviceSizes: [640, 750, 828, 1080, 1200, 1920],
    },
    async headers() {
      return [
        {
          source: '/static/:path*',
          headers: [
            {
              key: 'Cache-Control',
              value: 'public, max-age=31536000, immutable',
            },
          ],
        },
        {
          source: '/:path*.{jpg,jpeg,png,gif,svg,ico,webp,avif}',
          headers: [
            {
              key: 'Cache-Control',
              value: 'public, max-age=31536000, immutable',
            },
          ],
        },
      ]
    },
  }
  ```
- Create public directory with .gitkeep
- Add comment in next.config.js explaining cache strategy: static assets get 1-year cache, API routes get shorter TTL (configured in Phase 2)
- Document in code that Vercel automatically serves static assets from CDN with these headers
