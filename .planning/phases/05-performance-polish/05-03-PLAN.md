Prevent page jump when modal opens by locking scroll and compensating for scrollbar width:

1. Add scroll lock effect to GameDetailModal (src/components/game-detail-modal.tsx):
   - Import useEffect from React
   - Add effect that runs when `open` prop changes
   - Calculate scrollbar width: `window.innerWidth - document.documentElement.clientWidth`
   - Store current scroll position
   - Lock body scroll: `document.body.style.position = 'fixed'`
   - Compensate for scrollbar: `document.body.style.paddingRight = '{scrollbarWidth}px'`
   - Set body top offset: `document.body.style.top = '-{scrollY}px'`
   - Set body width: `document.body.style.width = '100%'`

2. Implementation pattern from RESEARCH.md Pattern 7:
   ```tsx
   useEffect(() => {
     if (!open) return;

     // Calculate scrollbar width
     const scrollbarWidth = window.innerWidth - document.documentElement.clientWidth;

     // Store original scroll position
     const scrollY = window.scrollY;

     // Lock scroll with compensation
     document.body.style.position = 'fixed';
     document.body.style.top = `-${scrollY}px`;
     document.body.style.width = '100%';
     document.body.style.paddingRight = `${scrollbarWidth}px`;

     return () => {
       // Restore scroll
       document.body.style.position = '';
       document.body.style.top = '';
       document.body.style.width = '';
       document.body.style.paddingRight = '';
       window.scrollTo(0, scrollY);
     };
   }, [open]);
   ```

3. Add header compensation (optional, if header is fixed):
   - If app has fixed header, also add paddingRight to header element
   - Prevents header from shifting when scrollbar disappears

4. Test on different platforms:
   - macOS: Scrollbars often hidden (0px width)
   - Windows: Scrollbars visible (~15-17px width)
   - Linux: Varies by desktop environment

Why position: fixed: Prevents background scrolling while modal open
Why calculate scrollbarWidth: Scrollbar width varies by OS/browser (0-17px)
Why paddingRight compensation: When overflow:hidden removes scrollbar, content shifts right to fill space
Why store scrollY: Restores exact scroll position when modal closes

This prevents the common "page jumps right by 15px" issue when modal opens on Windows.
