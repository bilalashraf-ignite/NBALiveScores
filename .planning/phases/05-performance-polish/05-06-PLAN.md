  ({ down, movement: [, my], velocity: [, vy], cancel, memo = contentRef.current?.getBoundingClientRect().top }) => {
    // Only allow drag from top of scroll (same logic as before)
    if (!down && my > 100) {
      // Crossed threshold - trigger close
      trigger('nudge'); // Existing haptic feedback
      onOpenChange(false);
    }

    // Apply transform directly to DOM via ref (no React re-render)
    if (contentRef.current) {
      const clampedY = Math.max(0, Math.min(my, 100));
      contentRef.current.style.transform = `translate(-50%, calc(-50% + ${clampedY}px))`;
    }

    return memo;
  },
  {
    axis: 'y',
    filterTaps: true,
    bounds: { top: 0, bottom: 100 },
    rubberband: true,
    threshold: 10,
  }

1. useDrag throttles updates via requestAnimationFrame (~60fps, not per-pixel)
2. Transform applied directly to DOM via ref (no React state → no re-render)

4. Library handles touch event passive flags correctly for Safari

**Replace with useDrag hook:**
```tsx
const bind = useDrag(
  ({ down, movement: [, my], cancel, memo }) => {
    // Only activate at top of page (same logic)
    if (!memo && window.scrollY !== 0) {
      cancel();
      return;
    }

    if (!down && my > 80) {
      // Crossed threshold - trigger refresh
      setIsRefreshing(true);
      trigger('success');
      onRefresh().finally(() => setIsRefreshing(false));
    }

    // Update indicator position and text via ref
    if (indicatorRef.current && my > 0) {
      const clampedY = Math.min(my, 120);
      indicatorRef.current.style.transform = `translateY(${clampedY}px)`;
      indicatorRef.current.style.opacity = String(Math.min(clampedY / 80, 1));

      // Update text based on threshold
      const textElement = indicatorRef.current.querySelector('[data-pull-text]');
      if (textElement) {
        textElement.textContent = my > 80 ? 'Release to refresh' : 'Pull to refresh';
      }
    }

    // Reset on release
    if (!down && indicatorRef.current) {
      indicatorRef.current.style.transform = 'translateY(0)';
      indicatorRef.current.style.opacity = '0';
    }

    return memo ?? true;
  },
  {
    axis: 'y',
    filterTaps: true,
    bounds: { top: 0, bottom: 120 },
    rubberband: true,
  }
);
```

**Update wrapper div:**
- Remove onTouchStart/Move/End handlers
- Add {...bind()} to apply gesture handlers
- Keep existing className with overscroll-behavior-y-contain

**Update indicator div:**
- Add ref={indicatorRef}
- Replace dynamic className/style based on pullDistance with initial hidden state
- Add data-pull-text attribute to text element for DOM manipulation
- Keep loading spinner logic based on isRefreshing

**Why this fixes Safari performance:**
- Same reasons as modal fix
- No per-pixel React state updates
- Direct DOM manipulation via ref
- requestAnimationFrame throttling built into useDrag
